# Cupertino design for Flutter

The Flutter Cupertino library is a collection
of widgets that implement Apple's iOS design language
for Flutter apps. The widgets have a similar look
and feel to iOS, including rounded corners, gradients,
and minimalistic design.
They also include iOS interactions and animations.


The following 15-minute video provides a high-level
glimpse of the Cupertino package:


[Watch on YouTube in a new tab: "Flutter's Cupertino Package"](https://www.youtube.com/watch/3PdUaidHc-E)

## More information

[#](#more-information)

To learn more about using the Cupertino
package with Flutter,
check out the following resources:


- The (mostly visual) [Cupertino widget catalog](/ui/widgets/cupertino)
   on doc.flutter.dev

- The [Cupertino library](https://api.flutter.dev/flutter/cupertino/cupertino-library.html) page in the API docs

- The [Cupertino API examples](https://github.com/flutter/flutter/tree/main/examples/api/lib/cupertino)
   on the flutter/flutter
   repo. ( [Instructions](https://github.com/flutter/flutter/tree/main/examples/api#api-example-code)) For example,
   to run `CupertinoSwitch`:


```
cd path/to/flutter
cd examples/api
flutter run lib/cupertino/switch/cupertino_switch.0.dart

```
